## 2026-07-21 — Fix resume-creation 402 error UX + gate bugs

**Bug:** POST `/api/resumes` returned HTTP 402 (Payment Required) for Free-plan users at the 3-resume limit. The block fired correctly per AGENTS.md rule #12, but the client showed a raw/generic error instead of an actionable upgrade prompt, and two latent gate bugs were present.

**Fix (5 files + 1 test):**
- `src/app/lib/api-client.ts` — added typed `ApiError` (carries `status` + parsed body); `request()` throws it. Backward compatible (extends Error).

- `src/app/lib/resume-limit.ts` (new) — `handleResumeLimitError(err)` detects a 402 and shows a sonner actionable toast (Upgrade action → `/pricing`, with "delete a resume" hint). Framework-agnostic.
