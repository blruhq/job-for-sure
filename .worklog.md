## 2026-07-18 — Replace ADMIN_EMAIL with Better Auth admin plugin (RBAC)

**Task:** Refactor ad-hoc env-based admin check into production-grade DB-backed RBAC.

**Decision:** Use Better Auth's official `admin()` plugin (not hand-rolled role column). Plugin gives role/banned/banReason/banExpires columns on `user` + `impersonatedBy` on `session`, plus 12 admin API endpoints, ban/impersonate capability, and automatic `role` exposure in session.

**Admin scope:** Monitor-only. Admins are locked out of normal user features (/chat, /resume, /ats, /applications). Admins see only the /admin dashboard. To debug user issues, admins use impersonation.
