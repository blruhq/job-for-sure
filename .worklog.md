### Problem
All 5 resume PDF templates rendered content in a single page. Long resumes (6+ sections) clipped at the page boundary instead of flowing to page 2.

### Root Cause
2-column templates (modern, executive, photo) used `flexDirection: 'row'` body containers. The `@react-pdf/renderer` wrapping engine's interaction with row layouts caused content to clip. Additionally, no `minPresenceAhead` was set on any section title — zero orphan/widow protection across all templates.

### Fix
- **2-column templates**: Added `fixed` prop to sidebar `<View>` in modern-pdf.tsx, executive-pdf.tsx, photo-pdf.tsx. Sidebar now repeats on every page while main column flows and paginates naturally.
- **All templates**: Added `minPresenceAhead={30}` to all 13 section title `<Text>` elements in render-sections.tsx for orphan/widow protection.
- **Test**: Added multi-page pagination test verifying ≥2 pages for long resumes.
